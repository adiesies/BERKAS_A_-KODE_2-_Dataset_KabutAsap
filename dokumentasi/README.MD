# Dokumentasi Proyek

## 1. Deskripsi
Dokumentasi ini berisi bukti proses pengerjaan
anotasi deteksi objek citra berasap menggunakan
platform Roboflow.

## 2. Proses Pengerjaan
1. Membuat project di Roboflow.
2. Mengunggah gambar ke dataset.
3. Membuat kelas objek.
4. Melakukan anotasi menggunakan bounding box.
5. Memeriksa hasil anotasi.
6. Membuat dataset version.

## 3. Kelas Objek
- Manusia
- Kendaraan
- Gedung
- Vegetasi
- Titik Api

## 4. Hasil Pengerjaan
Jumlah gambar yang dianotasi: 100 gambar.

Format anotasi: YOLO.

## 5. Bukti Dokumentasi
Bukti screenshot proses pengerjaan tersedia
di folder roboflow_screenshot.

Contoh hasil anotasi tersedia di folder
contoh_hasil_anotasi.
